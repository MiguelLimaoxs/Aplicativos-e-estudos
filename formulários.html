# Serve para criar um formulário # O label é para nomear algo, e o for (para) colocamos o ID de algo para que quando clicamos em cima do "Nome" nós abrimos a caixa de texto do input. # O input serve para uma pergunta ou, para a pessoa escrever algo dentro da caixa de texto, etc. O type fala que a pergunta vai ser do tipo texto, onde você escreve. O placeholder serve como uma marca d'água para mostrar para a pessoa oque ela tem que fazer na caixa de pergunta. Já o ID serve para reconhecer o input no label, por isso nós utilizamos o for no label. # caso queira colocar outro basta repetir o processo.

# O type senha a diferença dele que ao invés de aparecer oque você está escrevendo, esse você não irá conseguir ver oque você está escrevendo.

# O email ele faz que oque você escreva seja detectado com um email, e aparece até para salvar o login se você acertar o email. Esse "required" mostra que é necessário escrever algo nesse campo, se não fizer o site vai detectar e pedir para a pessoa colcoar algo dentro dele.
